# AVACA 0.9.1

## 更新內容

- 新增作品圖片 Prefix 路由學習：依實際驗證結果保存候選 family，支援自動探測、手動指定、統計檢視，以及在 Settings 匯出／匯入規則。
- 強化 DMM 與 MGStage 圖片探測、錯誤分類、有效圖片與 placeholder 驗證，並讓不同 Prefix 的下載可受控並行。
- 改善刮削進度與響應式對話框，統一中／英／日介面的刮削狀態文字，補充路由、刮削、設定與 Works 測試覆蓋。
