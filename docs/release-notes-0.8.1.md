# AVACA 0.8.1

## 更新內容

- Android release `build-number` 改為 2026，能從手動打包的
  `versionCode=2025` 版本直接更新；之後每次正式 Release 遞增 1。
- 改善設定頁的來源設定入口，以及作品頁、詳細頁的響應式返回按鈕。
- 改善 DMM 作品圖片候選網址與 fallback，降低抓取圖片失敗率。
- 延續 GitHub Release 的版本化資產命名、SHA-256 驗證、Android 系統安裝程式與 Windows portable 更新。

## Release 資產

- `avaca-0.8.1-arm64-v8a.apk`
- `avaca-0.8.1-arm64-v8a.apk.sha256`
- `avaca-0.8.1.zip`
- `avaca-0.8.1.zip.sha256`
