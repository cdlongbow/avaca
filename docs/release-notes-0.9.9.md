# AVACA 0.9.9

## 更新內容

- 新增可版本化的作品排除政策，支援系列策略、精確允許例外與待檢視結果。
- 移除以出演者數量推斷作品類型的限制，改以作品語義、來源證據與明確設定判定。
- 強化抓取工作政策快照、結果狀態、進度觀察與工作明細顯示，讓重試與待檢視結果可追蹤。
- 更新 Works 抓取設定介面、繁中/簡中/英文/日文本地化與相關回歸測試。
