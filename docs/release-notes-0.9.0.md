# AVACA 0.9.0

## 更新內容

- 新增作品關聯演員資料，保存來源、演員頁連結，並可依本機女優名稱與別名解析到本機頁面。

- 改善 Works、Work Detail 的響應式版面與關聯演員導覽，補齊中／英／日多語系文字與測試覆蓋。
