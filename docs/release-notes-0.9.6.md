# AVACA 0.9.6

## 更新內容

- 新增可持久化的抓取工作，支援暫停／恢復、取消、重試目標、來源進度與事件記錄。
- 新增抓取工作清單與詳細頁、資料健康檢查，以及設定頁與導覽的多語系支援。
- 新增抓取規則快照、版本化規則資源、欄位來源追蹤與資料轉移支援。
- 強化抓取工作協調、事件清理、取消流程與部分成功進度聚合，並補充回歸測試。
