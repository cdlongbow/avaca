# AVACA 0.9.7

## 更新內容

- 新增 AvBase 別名抓取選項，並將別名同步保存至女優資料。
- 強化抓取工作協調、來源結果、錯誤處理與資料更新後的 Works 清單刷新。
- 新增抓取工作批次選取與刪除，並防止刪除仍在執行中的工作。
- 新增資料健康檢查的分段警告與重新整理介面，單一檢查失敗時仍保留其他結果。
- 更新資料健康、抓取工作、別名與設定相關的多語系文字及回歸測試。
