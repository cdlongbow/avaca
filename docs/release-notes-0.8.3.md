# AVACA 0.8.3

## 更新內容

- 「作品 -> 所有來源」改為 Minnano AV 與 JavBus 並行搜尋，完成後依 canonical
  番號整合並去除重複作品。
- 將 `1start00408`、`start-408` 等等價番號正規化為同一作品；欄位合併維持
  Minnano AV -> JavBus 的固定優先序。
- 強化取消流程、來源失敗回報、圖片處理與刮削完成結果彈窗；結果需按「確認」
  後才會關閉，不使用底下的通知列。
- 補充跨來源刮削、canonical 番號、取消清理、圖片來源策略、驗證彈窗與響應式
  UI 測試。
