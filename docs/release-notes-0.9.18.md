# AVACA 0.9.18

## 更新內容

- 進階抓取規則支援完整番號與安全的結構化作品前綴，例如 `KCKC` 或 `KCKC-212`；加入明確邊界檢查，避免誤匹配無關番號。
- 更新英文、繁中、簡中、日文與日文地區 Settings 文案，清楚說明番號／前綴允許與排除規則。
- 更新 Settings compact／expanded goldens，並補上 policy／evaluator 回歸測試，確認允許或排除前綴能涵蓋所有符合的作品。
