# AVACA 0.9.2

## 更新內容

- 新增 AvBase 刮削來源：支援演員資料、作品分頁、作品 metadata、DMM 頭像與作品圖片 evidence，並與 JavBus 維持 deterministic 合併。
- 強化 evidence-derived 作品圖片路由學習：保存候選健康狀態、驗證與 quarantine 規則，並讓下載器使用安全的已觀測路由。
- 改善來源選擇、刮削進度、Settings／Works 響應式版面與多語系文字，補充新刮削與圖片路由的回歸測試。
