# AVACA 0.9.8

## 更新內容

- 強化多來源作品抓取、全域候選合併、正式作品識別、重試流程與結果進度統計。
- 改善 AvBase/JavBus 抓取與 DMM 圖片路由，並保留來源優先順序、別名與圖片下載結果。
- 新增及整理抓取來源設定、別名同步、抓取工作明細/刪除/重試與相關本地化介面。
- 修正 Detail、Works、Home、Settings 與資料庫生命週期行為，並更新回歸測試與 UI goldens。
