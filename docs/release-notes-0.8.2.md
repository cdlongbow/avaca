# AVACA 0.8.2

## 更新內容

- 新增 [Minnano AV](https://www.minnano-av.com/) 刮削來源。
- 女優詳細資料預設使用 Minnano AV；作品預設使用所有來源，依番號
  canonical code 整合並去重複。
- 詳細資料與作品來源可在「設定 → 其他 → 刮削來源」獨立選擇 Minnano AV、
  JavBus 或整合模式。
- 強化 Unicode 番號正規化、跨來源 detail 番號驗證、來源失敗/部分成功回報、
  取消流程與圖片來源限制。
