# AVACA 0.9.15

## 更新內容

- 補強作品 provenance 語義判定，涵蓋跨片商的導演剪輯、再編輯、再販／再發售、REPLAY 與有限條件的未公開映像 Premium Edition。
- 將 AvBase 與 JavBus parser 統一接到共享語義 helper，並避免僅出現在作品番號中的文字誤觸發 provenance 判定。
- 補上跨片商真實案例、parser parity、語義邊界與次要來源升級回歸測試，確保明確 derived work 不會不必要地升級查詢。
