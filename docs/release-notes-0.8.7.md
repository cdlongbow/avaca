# AVACA 0.8.7

## 更新內容

- 作品圖片路由改為只依製作商/發行商 metadata 判斷，新增 Seikyouiku
  MGStage 路由並擴充核准的 MGStage endpoint 驗證；不再從圖片證據反推路由。
- 修正女優名稱/別名搜尋中，前一個查詢失敗但後續查詢成功時仍被標成部分失敗的情況。
- 修正串流刮削的圖片下載/儲存進度，讓總數、目前進度、成功/排除/失敗數一致。
- Detail 頁的私人備註卡片可直接開啟編輯；作品與別名操作改為完整列寬，並即時儲存別名。
- Works 刮削設定的番號前綴在編輯時即時持久化，並統一圓角輸入框與設定對話框外觀。
