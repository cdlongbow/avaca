# AVACA 0.8.6

## 更新內容

- JAVBUS 作品詳細資料預設請求間隔調整為 0.6 秒。
- 每部作品詳細資料成功後立即排入有限並行的卡面與詳情圖片下載；圖片下載
  不會阻塞下一部 JAVBUS 詳細資料請求。
- 預設使用 Minnano AV 取得女優詳細資料、JAVBUS 取得作品資料。
- 移除標題相似、跨來源及版本猜測式作品合併，保留精確作品代號/網址的傳輸
  重複保護。
- 圖片路由改由製作商、發行商及頁面上的核准 DMM/MGStage 證據判斷，不使用
  JavBus 封面或番號前綴猜測網址。
