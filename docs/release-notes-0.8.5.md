# AVACA 0.8.5

## 更新內容

- 刮削進度在取得作品與詳細資料時只顯示網站名稱；下載圖片階段才顯示目前
  處理的番號。
- Minnano AV 與 JavBus 的作品管線會真正並行啟動，同一網站內的詳細資料仍
  依序處理，避免把「取得作品數」誤當成網站並行。
- 作品去重改用保守的名稱與番號流程：同名時優先保留沒有精確
  `[特典版]` 標記的作品，再用刮削後番號跨來源去重。
- Rebecca 同名番號衝突時取較短的番號，例如保留 `REBD-975`，不再保留
  `H_346REBD00975`；不同數字核心仍維持分開。
- 圖片下載流程會接收最終解析出的番號，並補充並行、去重、進度顯示與圖片
  下載測試。
