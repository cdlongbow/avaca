# AVACA 0.8.5

## 更新內容

- 刮削進度在取得作品與詳細資料時只顯示網站名稱；下載圖片階段才顯示目前
  處理的番號。
- Minnano AV 與 JavBus 的作品管線會真正並行啟動，同一網站內的詳細資料仍
  依序處理，避免把「取得作品數」誤當成網站並行。
- 作品去重改用保守的名稱與番號流程：同名時優先保留沒有精確
  `[特典版]` 標記的作品，再用刮削後番號跨來源去重。
- 番號正規化保留來源差異，只合併已驗證的表示法，例如 `SSIS875` 與
  `SSIS-875`、`START00023` 與 `START-023`；Minnano 缺番號時會以同名與
  日期/發行商等獨立欄位，向 JavBus 補回 `SSNI-190` 類番號。
- Rebecca 同名番號衝突時取較短的番號，例如保留 `REBD-975`，不再保留
  `H_346REBD00975`；不同數字核心仍維持分開。
- 每個來源會分別回報成功、部分成功、需要驗證、被阻擋、逾時與失敗頁面；
  跨來源已成功合併的作品不會再被重複列入失敗。
- 圖片只使用已核准的 DMM `ps/pl`、Prestige/MGStage `pf/pb` 與 Rebecca
  `h_346` 六種 URL 形式；番號前綴採明確登錄表，未知前綴直接回報失敗，
  不猜 URL，也不使用第七種 fallback。
- 圖片下載流程會接收最終解析出的番號，並補充並行、去重、進度顯示與圖片
  下載測試。
