# AVACA 0.9.11

## 更新內容

- 移除以相容性前綴或特定系列模式預先排除作品的路徑，作品分類只依具體 provenance evidence 與作品語義判定。
- 保留未知作品為待檢視，並以精確允許／排除規則處理明確的人工覆寫；不再以出演者數量或作品番號前綴作為排除依據。
- 更新 Works／Settings 的進階抓取規則介面與繁中／簡中／英文／日文本地化，移除已停用的前綴與系列選項。
- 補強 JavBus、作品抓取服務、政策快照與設定 UI 的回歸測試及 compact／expanded goldens。
